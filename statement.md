PROBLEM STATEMENT: 

Students need an interactive way to practice mathematics and check their understanding of different mathematical topics, it should topic of contains topics of elementary school to higher school. Design the program so student of from lower class to higher class can practice. Add as many question you can add. Try to reduce input from user to make program run faster and smoother.

Scope of the project:
 
 This project focuses to provide user a good practice in several topic of maths , and provide them instant result so they can improve faster.

TOPIC INVOVLED: 

1. Addition

2. Subtraction

3. Multiplication

4. Division

5. Differentiation

6. Integration



TARGETED USERS OF PROGRAM :

Students from class 1st standard to 12th class who want to practice mathematics and improve thier mathskill.


HIGH LEVEL FEATURES :

1. Topic Selection: user can select one of six available mathematical topics.

2. Randomized Questions: Questions are randomized before the quiz starts so that they do not always appear in the same order.

3. Immediate result: The program tells the user whether their answer is correct. If the answer is incorrect, the correct answer is displayed.

4. Quiz Termination: The quiz ends when 20  questionsof selected topic have been completed or when the user gives three incorrect answers.

5. Result Display :At the end of the quiz, the program displays the user's name, number of questions attempted,  number of correct answers and number of incorrect answers.
