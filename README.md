project topic-MATHS QUIZ 


PROJECT OVERVIEW:

A. Maths Quiz provide  students practice on  mathematics through topic-wise multiple-choice questions.
B.  In the starting of the project students have to enter name , and after that they can choose any one of the six topic from the following :
1.CHOOSE 1 FOR ADDITION
2.CHOOSE 2 FOR SUBTRACTION
3.CHOOSE 3 FOR MUTLIPLICATION
4.CHOOSE 4 FOR DIVISON
5.CHOOSE 5 FOR DIIFERNTION
6.CHOOSE 6 FOR INTEGRATION
C.  After selecting the topic the quiz will begin and student will get 20 question , each one by one.
*IT IS TO BE NOTED THAT IF STUDENT ANSWER 3 QUESTION INCORECTLY , QUIZ WILL END .*
D. In they they will see thier result along with thier name  , in which how many following thing will be shown:
1.Number of question attempted.
2.Number of incorrect answer given.
3.Number correct answer given.
 

FEATURES: 

*NON CODING / TECHNICAL FEATURES:*
F1- It provides practice on 6 topic.
F2- Student can choose thier topic  by themself.
F3- It terminates after 3 incorrrect answer given.
F4- Input taken from user is single letter (a,b,c,d) .
F5- Question are choosen randomly .
F6- It immediatley shows answer if answered wrong and instanly shows overall result after the quiz ends.

*CODING/TECHNICAL FEATURES:*
F1- As user has to give single letter input , program runs faster and efficently.
F2- Question are choosen randomly form the array .
F3- It can accept answer in both captial letter(A,B,C,D) and small letter (a,b,c,d).

TECHNOLOGY USED :

A. Python 3

B. Python Standard Library

C. Random moudle (pre installed in vs code)





HOW TO RUN

1. Install Python

Install Python 3 on your computer.

2. Open the Project Folder

Open a terminal or command prompt inside the project folder.

3. Run the Program

python main.py

INSTRCTION TO RUN PROGRAM:

I1-The program displays the welcome message.

I2-The user enters their name.

I3-The user selects one of the six mathematics topics.

I4-The user answers each question ,they can't skip any questio.

I5-The quiz stops when all questions are completed or when the user reaches 3 incorrect answers.

I6-The final result is displayed.
